# SQL ile Spotify Veri Analizi 
Bu proje, SQL alanında kendimi geliştirmek ve veri analizinin gerçek hayattaki kullanım alanlarını daha iyi anlayabilmek amacıyla geliştirdiğim ilk SQL projelerinden biridir.
Yönetim Bilişim Sistemleri öğrencisi olarak veri analizi, yapay zeka ve yazılım alanlarında kendimi geliştirmeye çalışırken, SQL bilgisini yalnızca teorik olarak öğrenmek yerine gerçek bir senaryo üzerinde uygulamak istedim. Bu doğrultuda Spotify benzeri bir müzik veri tabanı oluşturarak kullanıcı dinleme davranışlarını analiz etmeye yönelik bir çalışma geliştirdim.
Proje kapsamında kullanıcılar, sanatçılar, şarkılar ve dinleme geçmişi üzerine ilişkisel bir veri tabanı tasarlandı. Oluşturulan SQL sorguları ile en çok dinlenen şarkılar, popüler sanatçılar, kullanıcı bazlı dinleme alışkanlıkları ve müzik türleri üzerine çeşitli analizler gerçekleştirildi.

## Kullanılan Teknolojiler
- SQL
- SQLite
- GitHub

## Veritabanı Yapısı
Projede aşağıdaki tablolar oluşturulmuştur:
- Users
- Artists
- Songs
- Listening_History

## Gerçekleştirilen Analizler
- En çok dinlenen şarkılar
- En popüler sanatçılar
- Kullanıcı bazlı dinleme analizleri
- Müzik türü analizleri
- Şarkı süre analizleri

## Proje Dosyaları
- `schema.sql` → tablo yapıları
- `insert_data.sql` → örnek veriler
- `analysis_queries.sql` → SQL analiz sorguları
